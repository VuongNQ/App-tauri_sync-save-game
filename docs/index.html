Windows desktop app

Pick up where you left off.

Save Game Sync backs up your game saves to Google Drive and restores them on your Windows PCs.

Download for Windows View source on GitHub

How it works

Choose your save folders

Sign in with Google, then add each game and select the folder where it stores its saves.

Back up to Google Drive

Sync your saves to the app’s Google Drive storage. You can enable background tracking for individual games.

Restore on another PC

Sign in with the same Google account and sync to restore your saves. The app can also check for the latest save before launching a game.

See the Privacy Policy for details on how Save Game Sync uses Google account and Drive data.
