Privacy Policy

Effective November 18, 2026

Save Game Sync is a Windows desktop app that backs up and restores your game saves using Google Drive. This policy describes the data the app uses and the choices available to you.

Data we access and why

  • Google account. The app uses Google Sign-In and receives your Google account ID, email address, display name and profile picture when available. These identify your account and display your profile. Cloud Firestore stores the app’s account profile, including its role and registration and last-seen timestamps, for account management.
  • Game saves and backups. The app reads files from the save folders you choose. It uses Google Drive to upload, download, list, manage and restore app-specific save files, backup versions and sync metadata. The app can also store cover images you add and read older library data created by the app when migrating it to Firestore.
  • Game library and devices. Cloud Firestore stores your game library, app settings, device records and synchronization metadata so the app can use them across devices. Records can include game names, folder or executable paths, file timestamps, device identifiers or names and play time when tracking is enabled.
  • Local app data. The desktop app stores settings, state and Google OAuth tokens in its local application data directory. It uses the tokens to keep your session active and make the Google API requests you authorize.

Storage and sharing

The app sends data over HTTPS to Google services for authentication, Drive storage and Cloud Firestore. The project’s account-management tools display account profiles to app administrators. Save Game Sync does not sell Google user data or use it for advertising.

Save Game Sync’s use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Retention and your controls

  • Sign out. Signing out removes the locally stored Google OAuth tokens. You can also revoke access in your Google Account connections. These actions do not erase previously stored cloud data.
  • Remove backups. Save files and backup versions remain in Google Drive until deleted. You can delete individual files or versions through the app’s Drive and backup controls.
  • Request cloud data deletion. Firestore profile and other cloud records can persist after you uninstall the app. To request deletion, use the contact instructions below. Local copies of save files in the game folders you selected remain under your control.

Contact

For a privacy question or deletion request, ask the maintainer for a private contact channel through the project’s GitHub support page. Keep email addresses, tokens, save files and other personal information out of public issues.
